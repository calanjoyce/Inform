# Inform
Inform games development 

## Games

- [Lantern Hill](LanternHill/): a short Inform 7 game about an old observatory and a comet. Play `LanternHill.gblorb` in Lectrote, Gargoyle or at iplayif.com.
- [Keithwood](Keithwood/): a new game in design, set in the house I grew up in, layering memories of the past over the present. A one-room front yard demo, `Keithwood.gblorb`, tries out the time shift. See [DESIGN.md](Keithwood/DESIGN.md).
